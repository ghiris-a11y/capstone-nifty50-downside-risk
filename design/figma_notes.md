## Not copied
- Brand names (Stockin, Donka, Headername, MaxFit), logos, photos, placeholder text and numbers.
- "Buy" and "Get Started" buttons, candlestick charts, newsletter and social blocks.
- The kit's dark mobile theme: the phone layout stays light because it prints better.
- The kit's blue buttons and the template's pink gradients:
  - blue means machine learning in this project, so UI chrome is navy and charcoal;
  - the Start here header has only a faint warm-grey wash.
